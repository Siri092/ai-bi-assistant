# Mini AI Business Intelligence Assistant

A small assessment project that answers natural-language questions about sales data. FastAPI serves the API and UI, SQLite stores transactions, SQL performs deterministic calculations, and an optional LLM classifies the question into one of a fixed set of supported analytics intents.

## Features

- Imports `data/sales_data.csv` into SQLite at application startup.
- Supports total revenue, top product, monthly revenue trend, top region, and month-to-month comparison.
- Returns a natural-language answer and the supporting query result.
- Optional OpenAI-powered intent classification; without an API key, uses a local intent interpreter.
- Never executes SQL generated by the LLM. The model can only select a whitelisted intent and month parameters.
- Includes automated tests and a simple browser UI.

## Revenue and data-quality rules

Revenue is calculated as `(quantity * unit_price) - discount_amount`.
Only `Completed` transactions with positive quantity and non-missing, non-negative numeric values are included. Returned transactions are excluded. Records with missing unit price remain in the database for traceability but are excluded from revenue metrics. This is a deliberate rule for this assessment; in a real system, missing prices should be reviewed with the data owner.

## Setup (Windows)

1. Install Python 3.11 or newer.
2. Extract the project folder and open it in VS Code.
3. Open Terminal in the project root.
4. Create and activate a virtual environment:

   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```

5. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

6. Optional: copy `.env.example` to `.env` and add your OpenAI API key. Without a key, local question interpretation still works.
7. Start the app:

   ```powershell
   uvicorn main:app --reload
   ```

8. Open `http://127.0.0.1:8000` for the UI or `http://127.0.0.1:8000/docs` to test the API.

## Example questions

- What is the total revenue?
- Which product generated the highest revenue?
- What is the monthly revenue trend?
- Which region generated the highest sales?
- Compare revenue between 2026-01 and 2026-02

Month comparison requires months in `YYYY-MM` format.

## Run tests

```powershell
pytest -q
```

## API

`POST /ask`

Request:

```json
{"question": "What is the total revenue?"}
```

Response includes `answer`, `data`, `intent`, `question`, and `interpretation_method`.

## Architecture

Browser UI -> FastAPI `/ask` -> question interpreter -> whitelisted analytics intent -> predefined parameterized SQL -> SQLite -> structured response with supporting figures.

The LLM never writes or executes SQL. The backend only dispatches to predefined query functions, which prevents destructive SQL operations and limits unsupported questions.

## Known limitations

- The local interpreter recognizes a limited set of phrasings. Use the example questions if it does not recognize a request.
- Month comparisons require explicit `YYYY-MM` values.
- The app is a local assessment prototype, not production-hardened; it has no authentication or deployment configuration.
- If the LLM key or service is unavailable, the app silently falls back to local interpretation.
